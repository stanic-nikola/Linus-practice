Diese Dateien sind nur für die gemeinsame Mentoring-Session gedacht.

1. Entpacke diesen Ordner und öffne ihn in VS Code (`Datei > Ordner öffnen`).
2. Starte Live Share und teile den Einladungslink mit deinem Mentor.
3. Öffne `index.html` in einem Browser oder mit der Live-Server-Erweiterung.
4. Erkläre die vorhandenen HTML-Elemente und Attribute.
5. Ergänze das Login-Formular anstelle des TODO-Kommentars.
6. Schreibe die drei CSS-Regeln in `styles.css`.
7. Erkläre deine Entscheidungen selbstständig.

**Hinweis:** `/login` ist kein vorhandener Server-Endpunkt. Es geht hier um HTML, nicht um einen funktionierenden Login. Beim Absenden kann deshalb ein Fehler erscheinen.

**Wichtig:** Die Hausaufgabe ist ein separates Projekt mit eigenen Starterdateien.
